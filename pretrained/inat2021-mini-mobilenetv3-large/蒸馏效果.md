# 蒸馏权重对比 · 四张表

日期：2026-09-29 ｜ 硬件：单卡 NVIDIA RTX 3090

## 蒸馏方法（简述）

下表中「蒸馏权重」的产法如下（对照臂「仅标签」＝同一流程去掉蒸馏项）：

| 项        | 内容                                                                                     |
| -------- | -------------------------------------------------------------------------------------- |
| **教师**   | 冻结的 **DINOv3 ViT-B/16**（LVD-1689M 权重），另在 iNat 上训练一个 **10,000 类线性探针头**               |
| **学生**   | **MobileNetV3-Large**，从 ImageNet 预训练权重出发（与表中「ImageNet 权重」是同一份起点）                       |
| **数据**   | iNaturalist 2021 **mini** 训练集：**50 万图 / 10,000 类**（官方 `train_mini` 划分）                  |
| **损失**   | `0.5 × CE + 0.3 × T²·KL(教师 logits ‖ 学生 logits)`，温度 **T = 3**                           |
| **训练**   | 输入 **224×224**；两个固定增强视角逐 epoch 交替；**20 epoch**；教师输出离线缓存后再训练学生                             |
| **验证**   | iNat 官方 val（10 万张）：仅标签 **51.78%** → 蒸馏 **58.40%**；教师线性探针 **71.38%**                   |
| **产物**   | `inat2021-mini-mobilenetv3-large-backbone.safetensors`（骨干，torchvision `features.*` 键）+ `inat2021-mini-mobilenetv3-large-classifier.safetensors`（含 10,000 类头） |

## 说明

- **表 1 / 表 2 的协议**：骨干**完全冻结**，取池化特征做 L2 归一化，用闭式 ridge 回归做分类头；每类抽 5 张训练（同一 seed 下各模型共用同一份子集），ridge 的 λ 在官方 train 划分的留出集上选择；在官方 test 上评一次；3 个 seed 取均值。表中为 **top-1**。
- **每个模型用自己的官方预处理**：
  - MobileNetV3 家族中 **ImageNet-1k 权重与蒸馏权重**：「短边 resize 256 + 中心裁剪 224 + ImageNet 归一化」；
  - MobileNetV3 **ImageNet-21k 权重**：几何相同，但**不做归一化**（timm 元数据 `mean=(0,0,0), std=(1,1,1)`，即直接吃原始 [0,1] 像素）；
  - **DINOv3 ViT-S**：「resize 256 + 裁剪 256 + ImageNet 归一化」，特征取 **CLS token**。
- **四个权重**：

| 表中列名            | 具体权重                                                                                                                          | 参数量    | ID  |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------ | --- |
| ImageNet 权重     | torchvision MobileNetV3-Large `IMAGENET1K_V2`，**ImageNet-1k（1,000 类）**，官方 acc@1 75.274% / acc@5 92.566%                       | 2.97M  | —   |
| ImageNet-21k 权重 | timm `mobilenetv3_large_100.miil_in21k_ft_in1k`，**ImageNet-21k 预训练后再在 1k 微调**，权重标注 1k top-1 78.0%                             | 2.97M  | —   |
| 蒸馏权重            | `inat2021-mini-mobilenetv3-large-backbone.safetensors`：iNat mini 50 万图 / 10,000 类 / 20 epoch，冻结 DINOv3 ViT-B 教师蒸馏 | 2.97M  | —   |
| DINOv3 ViT-S    | timm `vit_small_patch16_dinov3.lvd1689m`（自监督，无分类标签）                                                                           | 21.59M | —   |

- **蒸馏权重是从「ImageNet 权重」出发训练的**（蒸馏与仅标签两组都从 ImageNet 预训练的 MobileNetV3-Large 开始），因此表 1 / 表 2 / 表 3 中这两行的差别是中间多了一段 iNat 训练。
- **表 3 的协议**：**全部解冻**端到端训练，epoch 固定 **20**，分类头为 `LayerNorm → Linear`；训练中只看官方 val，**不使用 test 选模型**，表中为**最后一个 epoch** 的官方 test top-1；3 个 seed 取均值。
- **表 4 的测量**：RTX 3090，bf16，仅模型前向、输入已在 GPU；参数量为**骨干**参数量。
- 数据集：CUB-200-2011（200 类，train 5,994 / test 5,794）；NABirds（555 类，train 23,929 / test 24,633）；**Oxford Flowers-102**（102 类，train 1,020 / val 1,020 / test 6,149）；Stanford Cars（196 类，train 8,144 / test 8,041）。

## 表 4 · 参数效率（ViT-S vs MobileNetV3-L 蒸馏权重）

| 项目            | MobileNetV3-L（蒸馏权重） | DINOv3 ViT-S/16 |
| ------------- | ------------------- | --------------- |
| 骨干参数量         | **2.97M**           | 21.59M          |
| 输入分辨率         | 224                 | 256             |
| batch1 延迟 p50 | **1.69 ms**         | 2.99 ms         |
| batch1 延迟 p95 | **1.74 ms**         | 3.06 ms         |
| batch32 吞吐    | **7,234 图/s**       | 1,775 图/s       |
| 推理峰值显存        | **200.3 MiB**       | 244.7 MiB       |

> 注：MobileNetV3-L 的 **ImageNet-21k 权重**与蒸馏权重是同一架构（2.97M / 224），实测延迟与吞吐同量级：**1.67 ms（p50）/ 1.74 ms（p95）/ 7,269 图/s / 200.3 MiB**。
