# 训练测试集错分分析

工具 `training.analyze_test_errors` 已实现，是第 15 个工具。它只读取已保存、经过完整性校验的训练报告，不重新推理、不训练、不修改标签，因此无需写操作确认。

## 使用

在成功完成的训练详情页点击「分析测试集错分」，助手会新建空白对话并填入该训练的问题；点击发送后开始查询。也可以直接问：“分析训练 <run_id> 最终测试集为什么分类错误。”

```json
{
  "run_id": "训练运行 UUID",
  "max_confusion_pairs": 10,
  "max_examples": 10
}
```

后两项可选，范围均为 1–20。接口为 `POST /api/agent-tools/invoke/training.analyze_test_errors`，外层沿用 `{"arguments": ...}`。只对当前有权限的管理员和业务账号开放；后台委托仍会复核当前登录会话和角色。

## 返回内容

- 独立测试集样本数、错分数、accuracy、macro-F1。不能与训练概况中可能合并 val/test 的历史指标混用。
- 按错分数量排序的易混类别对及类内比例。
- 最多 20 个高错分类别的测试支持数、错误率、训练支持数；缺失的历史训练支持数返回 null。
- 高置信错分数量，以及前两类概率差较小的错分数量。
- 典型错分的 sample_id、真类、预测类、原始 softmax 概率、真类概率、前两名 margin、Top-3 候选。
- `findings` 明确分为 `observed`（计数事实）和 `hypothesis`（需继续验证的排查方向），另提供下一步建议与数据局限。

新报告在训练结束、最终模型对样本产生预测之后计算证据，严格筛选 `split == test`。不使用训练或验证样本代替测试样本，不根据错误分析自动调整模型。线性头原有 headline 指标维持兼容，但新工具只使用额外保存的 test 证据。

每份报告最多保留 200 对易混类别、50 个错分示例；示例按错误预测的概率降序、sample_id 排序。工具最多返回其中 20 个，示例不是随机抽样，不能用示例频率估计总体错误分布。

高置信默认阈值为 0.8，低分差阈值为 0.1，训练样本少于 10 是排查启发式。这些分数是**未校准的 softmax**，不代表经过验证的真实正确概率。这些阈值也不是普适的原因判定标准。

## 历史兼容

| availability | 含义 |
|---|---|
| available | 有新版本 Worker 保存的独立测试证据，可看统计和已保留的样本 |
| aggregate_only | 旧报告明确来自 test，但没有逐样本预测；只能读聚合统计，不能编造样本或置信度 |
| unavailable | 未完成、无可校验报告、没有测试样本，或旧报告未证明独立测试范围 |

旧矩阵的类别顺序必须来自同一训练、通过校验的模型 bundle，并与报告支持数相符。缺失时不按字母排序猜测类别对。尤其旧线性头曾合并 val/test 评估，此类历史报告不会被重新标为 test。

这不要求数据库迁移：新字段保存在现有 `training_report.json` 的 `evaluation.error_analysis` 中。旧 Worker 仍能完成训练，但不会生成新证据；需要更新实际执行训练的 Worker 镜像，才能给新训练提供完整分析。已有旧训练不会自动补算或重训。

## 实现与资源边界

Python 在 `ml_toolkit/error_analysis.py` 计算独立测试证据，图像训练与线性头均接入。Go 从该训练关联的已校验 report 制品读取，通过 SHA-256 / 长度校验后生成受限摘要。报告与训练、数据版本必须匹配。

单控制面进程最多并行读取 2 份分析报告；报告限制 16 MiB，类别顺序 bundle 限制 1 MiB；使用短期临时目录，完成后清理。Agent 继续遵守原有只读工具并发限制。

本工具不读取原图。因此“遮挡、背景依赖、模糊、视觉相似、标签错误”等只能作为待检查假设，不能声称已经证实。若据此迭代训练，应另外保留独立评估集，避免持续针对同一测试集调参。

## 验证

- Python：测试/验证严格隔离、ID 对齐、零测试样本、示例上限、稳定排序、非法预测拒绝，以及训练写入路径。
- Go：跨语言报告契约、test-only 指标、历史混合划分拒绝、模型类别顺序校验、错误报告拒绝、认证和输出上限。
- PostgreSQL + 文件制品：真实关联查询、训练未完成、SHA 损坏拒绝。
- 本地真实链路：小样本训练成功，独立 test 为 3 个样本、2 个错分；accuracy = 0.3333、macro-F1 = 0.1667。2026-10-25 再次通过真实模型核对，回答与训练侧指标分开说明；旧混合报告返回 unavailable。
- 浏览器：已完成训练的入口、训练 ID 传递、独立新会话，以及点击入口不自动发送模型请求。

真实训练验收脚本为 `agent/tests/smoke_test_errors.py`，需显式提供测试账号、最多 16 个样本的测试版本及 `--confirm-test-training`；常规分析无需这些测试参数。
