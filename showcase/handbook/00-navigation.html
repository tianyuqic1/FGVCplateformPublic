0. 展示导航与页面路由

本文严格按“产品是什么、如何使用、为什么这样实现、如何验证、怎样查工程契约”的顺序组织。正文是一份连续长文档，左侧目录可直接定位章节；产品入口仍指向实际 React 页面，文档本身不复制业务状态，也不触发任何有副作用的接口。

0.1 文档模块

01 / PRODUCT

项目介绍

问题背景、产品目标、端到端闭环和当前实现边界。

02 / MANUAL

操作手册

按产品路由解释输入、操作、状态变化、产物和排错入口。

03 / ENGINEERING

项目实现细节

控制面/计算面、状态机、训练、发布、推理、标注与可靠性设计。

04 / EVALUATION

评估测试报告

固定测评矩阵、指标、工具调用统计、数据泄漏防护和复现规则。

05 / REFERENCE

附录

API、核心表、容器、环境变量、模型与数据版本规则的快速索引。

0.2 产品页面路由

模块路由主要任务关键边界
工作台/ ↗查看全局状态和优先事项汇总视图，不替代各详情页审计记录
数据集/datasets ↗异步导入、检索、查看不可变版本名称不是身份；版本与 manifest 共同定位样本
数据集详情/datasets/:datasetId版本、类别、split、样本预览与数据说明注册版本的原标签与 split 不原地修改
AI 标注/annotation ↗批量分析、人工确认、记忆入库和数据发布AI 只给候选；只有人工确认可形成标签
训练/training ↗创建任务、筛选队列、查看指标曲线业务任务与每次 Worker 执行尝试分离
训练详情/training/:runId审计配置、attempt、指标、产物和失败原因迟到 attempt 不得覆盖当前执行结果
推理实验室/inference ↗选择数据集和已发布部署，执行单图/批量推理未发布模型、SHA 不匹配或部署未就绪均不可用
权重/weights ↗核对预训练权重登记与节点缓存Git LFS 发布记录不等于计算节点已经缓存
人工复核/review ↗处理弃权和人工指定复核样本LLM 建议不能自动提交最终结论
反馈池/feedback ↗查看复核反馈、生成/回放阈值候选反馈不直接改写已注册数据版本
模型版本/models ↗按数据集聚合、同范围比较、发布部署只比较同一数据集版本下的模型
流水线/pipelines ↗观察异步任务、事件和重试状态来自持久事件，不由页面模拟
硬件监控/hardware ↗查看计算节点、GPU/CPU/内存与历史趋势缺失指标显示未采集，不伪装成零
阅读约定。文档中的状态、事务边界和限制均按当前仓库实现书写；“计划支持”不会混入“已经完成”。对外部署时应把上表的 localhost 替换为真实产品地址。
