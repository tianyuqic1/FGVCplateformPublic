5.4 类别目录 JSON 契约

{
  "schema_version": 1,
  "name": "CUB-200 catalog",
  "classes": [
    {"id": "001", "name": "Black-footed Albatross"},
    {"id": "002", "name": "Laysan Albatross"}
  ]
}

当前仅支持 JSON 导入。classes 数量必须为 2–1000，id 与 name 非空且分别唯一，未知字段被拒绝。数据库 JSONB 保存经校验的权威目录；下游模型调用、人工确认、CLIP 文本原型和数据发布都读取同一目录，不在不同接口里各自解析可变文件。

5.7 MinIO 对象布局

datasets/{dataset_id}/{dataset_version_id}/
  source.zip
  manifest.json
  publication-plan.json

models/{dataset_id}/{model_version_id}/
  checkpoints/model.pt
  releases/v1.0.0/model-fp32.onnx
  releases/v1.0.0/model-fp16.onnx
  deployments/{deployment_id}/engine.plan

reports/{training_run_id}/
  training.json
  calibration.json
  export-parity.json

逻辑上先按数据集、再按模型版本两层区分；对象 key 方便运维定位，但访问权仍由数据库 descriptor 决定。每个可执行对象记录 SHA-256 和 size，Worker 下载后先校验再加载。

5.8 模型推理后端能力

后端输入产物当前门禁验证状态表达

5.9 端到端数据流参考

# 数据集导入
Frontend → multipart → Go validation → Job + Outbox
         → RabbitMQ → import worker → MinIO object + manifest
         → descriptor transaction → Dataset Version ready

# 训练与发布
Training form → Go Job/Attempt → RabbitMQ → Training Worker
              → PT checkpoint + metrics + calibration
Publish → merge LoRA (if any) → full ONNX → parity/SHA/size
        → production release → ready deployment → inference selectable

# 推理与人工反馈
Image + released deployment → Inference Runtime → logits
→ temperature + policy → inference event
→ accept OR review item → human feedback → shadow policy → manual activation

# AI 标注到数据版本
JSON catalog + images → batch snapshot → tool/VLM workflow
→ Top-10 → human confirm + memory outbox
→ Qdrant idempotent upsert → publication preview
→ new dataset / new version → deterministic split → training

5.12 术语表

术语定义
Dataset业务数据资产，可拥有多个不可变 Dataset Version。
Training Run一次用户训练意图；恢复时可以产生新的 Attempt。
Attempt某个 Worker 在一个 execution epoch 中的具体执行权。
Model Version训练产出的候选模型及其语义版本身份。
Release通过发布门禁并冻结的模型语义版本。
DeploymentRelease 在特定后端、精度和硬件 profile 下的可执行产物。
Abstain证据不足时不自动给最终结论，转入人工复核。
Shadow Policy只回放并记录差异、不影响实际在线决策的候选阈值。
Annotation Memory由人工确认样本构成、按目录与编码器 revision 隔离的检索记忆。
Publication Preview提交数据版本前冻结的样本、去重与 split 计划。
