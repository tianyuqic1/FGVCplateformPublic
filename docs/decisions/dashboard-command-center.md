# 首页重构决策：任务指挥台 + 证据检查器

## 决策

首页采用“任务指挥台”作为主结构，并吸收科研仪器台的证据检查器与发布航线的链路追踪能力。全站应用外壳统一为暖白底、深蓝灰文字、细边框和低饱和语义状态色。

## 信息口径

- 待复核总数只在接口返回 `pagination.total` 时显示总量；否则显示“已读取 N 条”。
- 成功训练且关联模型版本的运行数不等同于待发布候选；候选数量来自模型注册表的 `candidate + staging`。
- 不展示缺少业务分母的装饰性覆盖率或进度条。
- 发布检查将“系统验证结果”和“建议人工核查项”分开；后者不能显示为系统通过。
- 首页发布读数始终绑定当前选择的模型版本。
- 复核进入反馈池不等同于自动成为训练数据，仍需策展并发布新的不可变数据版本。

## 页面分工

- 首页：确定先处理什么，并展开最小必要证据。
- 复核与训练详情：完成判断或故障诊断。
- 模型版本页：执行正式发布操作。
- 流水线：追踪推理异常到发布的完整证据链。

## 原型清理

A–E 原型和 `/prototype/dashboard` 路由已删除，选定方案已重写为正式首页组件。
