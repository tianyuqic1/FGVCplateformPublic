- `go test ./...`：通过。

- `npm run test:run`：9 个测试文件、15 个用例通过；覆盖搜索映射、请求取消/超时、分页、跨页模型选择和冷加载空状态。

- 本地容器与接口联调：前端 `http://localhost:5173`、Go 控制面 `http://localhost:8001`；真实浏览器逐页操作搜索、列表筛选与翻页、失败详情、历史预览、权重说明、复核详情、推理取消及移动导航。浏览器错误日志为空。

## 仍需明确的边界

1. `cifar10-mini` 的原图片归档在当前存储中不可读取。本轮修复的是“不可用却返回可点击图片 URL”的契约问题；要恢复预览，必须找到并重新导入对应原图，不能根据标签凭空重建。
2. 取消的是浏览器等待和可传递的请求上下文，不保证已经进入推理 worker 的计算立即停止；界面对此明确提示。后端尚未上报可验证的逐阶段进度，因此本轮只显示等待时长，不宣称真实完成百分比。
3. 首页跨全部运行与模型版本的运营汇总仍读取完整列表；本轮服务端分页已覆盖三个主要列表页。数据量明显扩大前，建议将首页汇总也改为专用统计查询。
